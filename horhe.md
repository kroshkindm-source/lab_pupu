# Краткое описание системы
В системе будет отслеживаться учёт студентов в общежитии. Такая система должна хранить сведения о студентах, проживающих в общежитии,
а именно: 
* ФИО студента
* Номер общежития и комнаты
* Паспортные данные
* номер студенческого билета
* группа
* институт
* контакты

это будет реализовано с помощью ЯП *python*, СУБД *postgreSQL*, API *postman*

### Основные задачи системы:

- упростить процессы заселения и выселения
- контроль за нарушениями студентов
- оптимизация использования площади общежития
- помощь студенту и заведующему этажом отслеживать нарушения

### Пользователи системы
* студент
* комендант
* заведующий общежитием

Данная программа будет помогать оптимизировать площадь общежития, помогать селить студентов с одной группы или направления вместе,
чтобы облегчить студенту обучение, данная система облегчит связь со студентом, контроль нарушений
